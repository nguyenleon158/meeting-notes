# Security Policy

## Supported versions

Security fixes are provided for the latest published version of MeetNote.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected vulnerability or attach
recordings, transcripts, provider keys, personal data, or diagnostic files to a
public post.

Contact Nguyen Leon privately through [nguyenleon.com](https://nguyenleon.com)
with:

- the affected MeetNote version and operating system;
- clear reproduction steps and the expected impact;
- a minimal proof of concept, if one is safe to share; and
- a diagnostic JSON generated by **Settings → Support & Diagnostics → Report a
  Bug**, when relevant.

Review the JSON before sending it. MeetNote does not automatically upload bug
reports. Please allow reasonable time for acknowledgement and remediation before
public disclosure.
